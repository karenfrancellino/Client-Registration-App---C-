## 📌 About the Project

This C++ console application allows users to register client information and store it in a text file.

---

## 🚀 Features

- 👤 Client data input
- ✅ Age validation
- 💾 File storage (`clientes.txt`)
- 🧱 Object-Oriented Programming

---

## 🛠️ Technologies

- C++
- Standard Library (`iostream`, `fstream`, `string`)
